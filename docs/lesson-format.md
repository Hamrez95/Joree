# قالب Markdown فعلی

هر کارت با عنوان شروع می‌شود و بعد از آن متن قرار می‌گیرد. خط مستقل `---` کارت‌ها را جدا می‌کند.

```markdown
# عنوان کارت

متن کوتاه کارت.

---

# یک سؤال؟

اول فکر کن.
پاسخ: پاسخ کوتاه سؤال.
```

نام درس در پیش‌نمایش قابل ویرایش است. کارت بدون عنوان یا متن، فایل خالی و فایل بزرگ‌تر از ۲ مگابایت رد می‌شوند. برای کارت با متن بیشتر از ۵۰۰ نویسه در پیش‌نمایش نشانهٔ متن بلند نمایش داده می‌شود؛ این محدودیت ورود نیست و متن در ناحیهٔ مطالعه پیمایش می‌شود.

نمایشگر از پاراگراف، تیتر، فهرست خط‌تیره‌ای، کد حصاردار، کد درون‌خطی، متن پررنگ و لینک وب پشتیبانی می‌کند. HTML خام اجرا نمی‌شود. تصاویر برای SVGهای همراه دوره در مسیر `images/*.svg` فعال‌اند؛ تصاویر بیرونی یا مسیر فایل محلی بارگذاری نمی‌شوند. فایل‌های `lab/lab.mjs` و `lab/data.json` همراه دوره قابل‌ذخیره هستند. این زیرمجموعهٔ Markdown است؛ جدول، فرمول LaTeX و بستهٔ عمومی تصویرهای واردشده پشتیبانی نمی‌شوند.

شناسه‌های پایدار در دادهٔ ذخیره‌شده تولید می‌شوند. قالب پیشرفتهٔ frontmatter، شناسهٔ نویسنده و فصل‌بندی چندگانه در واردکنندهٔ فعلی پشتیبانی نمی‌شود؛ فصل‌های درس نمونه از قبل تعریف شده‌اند.
