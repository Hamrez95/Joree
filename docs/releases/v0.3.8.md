# Joree v0.3.8 — Buttons stay clickable ☕

Raised the title-bar buttons above the invisible resize-corner hit areas. Pin, compact, minimize, and close can now receive the mouse normally; resizing still works around them.

## Downloads

- **JoreeSetup.exe** installs for your Windows account without administrator elevation.
- **Joree-0.3.8-win-x64.zip** is the extract-and-run build.
- The release includes a lesson template, installation notes, and SHA-256 checksums.

Requires 64-bit Windows, .NET 10 Desktop Runtime x64, and Microsoft Edge WebView2 Runtime.
