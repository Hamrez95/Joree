# Joree v0.3.3 — Give every lesson its own shelf ☕

This update adds nested collections for organizing lessons and keeps a clear way back from Settings.

## What changed

- The existing workplace AI lessons now live in the **هوش مصنوعی (AI)** collection.
- Create top-level collections or nested collections, rename them, and move them within the tree.
- Choose a collection when importing a lesson, or move an existing lesson from its detail page.
- Delete a collection without deleting lessons; its lessons move to the parent collection and its child collections move up one level.
- Settings now has a persistent **بازگشت به کتابخانه** button at the bottom of the page.
- Existing study progress, notes, and preferences stay in the same local database.

## Downloads

- **JoreeSetup.exe** installs for your Windows account without administrator elevation.
- **Joree-0.3.3-win-x64.zip** is the extract-and-run build.
- The release includes a lesson template, installation notes, and SHA-256 checksums.

Requires 64-bit Windows, .NET 10 Desktop Runtime x64, and Microsoft Edge WebView2 Runtime.
