# Joree v0.3.7 — Your study buddy is one shortcut away ☕

- Press **Ctrl+J** anywhere in Windows to show or hide Joree while it is running in the tray.
- Lesson text now has a little breathing room beside its scrollbar.
- The **Aa** control now responds on long lessons and makes text smaller with each press. Existing size settings are preserved during upgrade.

## Downloads

- **JoreeSetup.exe** installs for your Windows account without administrator elevation.
- **Joree-0.3.7-win-x64.zip** is the extract-and-run build.
- The release includes a lesson template, installation notes, and SHA-256 checksums.

Requires 64-bit Windows, .NET 10 Desktop Runtime x64, and Microsoft Edge WebView2 Runtime. The global hotkey is active while Joree is running, including when hidden in the tray.
