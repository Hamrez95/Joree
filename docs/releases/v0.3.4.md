# Joree v0.3.4 — Let the lesson breathe ☕

This polish pass puts the reading card first and trims back the handheld-console chrome.

## What changed

- Removed the floating star, clouds, and decorative underline from study cards so they no longer compete with lesson text.
- Reduced the console bezel, outer peach edge, top window controls, and footer navigation buttons.
- Shrunk and spaced both speaker-dot groups to keep them clear of the break button and footer tabs.
- Moved the bookmark control into the lesson header and made it smaller.
- Tightened reading-card spacing and typography for a clearer, more useful reading area.

## Downloads

- **JoreeSetup.exe** installs for your Windows account without administrator elevation.
- **Joree-0.3.4-win-x64.zip** is the extract-and-run build.
- The release includes a lesson template, installation notes, and SHA-256 checksums.

Requires 64-bit Windows, .NET 10 Desktop Runtime x64, and Microsoft Edge WebView2 Runtime.
