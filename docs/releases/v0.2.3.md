# Joree v0.2.3 — Your first little sip ☕

Meet Joree (جرعه): a cozy Persian-first desktop flashcard console. Bring Markdown, study a few small cards, and take an arcade break whenever you like.

## Grab a seat

- **JoreeSetup.exe** — per-user Windows x64 installer; adds desktop and Start shortcuts.
- **Joree-0.2.3-win-x64.zip** — extract everything and run `Joree.exe`.
- **Joree-lesson-template.md** — edit and import your first lesson.
- **INSTALL.md** — prerequisites, setup, backups, and troubleshooting.
- **SHA256SUMS.txt** — hashes for the downloadable files.

## Before the first sip

Confirm **.NET 10 Desktop Runtime x64** and **Microsoft Edge WebView2 Runtime** are installed. The app installer doesn't request administrator elevation. Installing missing shared runtimes may still need IT approval. The ZIP has the same prerequisites.

Open **جرعه** on the desktop or **Joree** in Start. Choose **کتابخانه → افزودن درس → انتخاب فایل**, select a `.md` lesson, review it, and add it to the library.

## What's working

Markdown import, sample courses, study/answer reveal, recall scheduling, notes, bookmarks, local progress, JSON backups, compact study mode, tray controls, window placement, and optional Blocks, Snake, and Pong.

Progress is saved locally in SQLite. Closing hides the console in the tray; **خروج کامل** exits it.

## Honest preview notes

- The UI is Persian/RTL; public setup docs are English.
- The downloadable host is **.NET / WebView2**. Tauri is an earlier scaffold.
- Binaries are **unsigned**; follow your organization's approval process if restricted.
- Advanced lesson updates, sign-in startup, native reminders, and the garden theme are unfinished.
- Generated promotional illustrations are artwork; the README gallery contains actual UI captures.
