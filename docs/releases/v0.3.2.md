# Joree v0.3.2 — A pocket-sized console that still reads well ☕

The Joree window can be resized from its edges and corners. Every screen now reflows its content for the space available, so text, controls, and icons stay in their own lanes as the window gets smaller.

## What changed

- Lesson cards and review rows wrap their titles cleanly; long descriptions no longer push into icons or counters.
- Study, progress, settings, notes, lesson import, and arcade layouts use smaller spacing and type in a narrow window.
- Side-by-side panels stack when there isn't room, and content scrolls vertically inside the screen when it needs more space.
- Horizontal scrolling is removed from the learning screens.
- Your local courses and progress stay in the same database when you update.

## Downloads

- **JoreeSetup.exe** installs for your Windows account without administrator elevation.
- **Joree-0.3.2-win-x64.zip** is the extract-and-run build.
- The release also includes a lesson template, installation notes, and SHA-256 checksums.

Requires 64-bit Windows, .NET 10 Desktop Runtime x64, and Microsoft Edge WebView2 Runtime.
