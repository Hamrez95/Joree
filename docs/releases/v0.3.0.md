# Joree v0.3.0 — Bring your work brain ☕

The demo shelf has graduated. Joree now includes a Persian learning path for workplace AI: 8 lessons, 83 substantial cards, 24 self-check questions, four explanatory diagrams, official sources, and a small runnable lab.

Start with LLM basics, then work through prompting, RAG, evaluation, local infrastructure, agents, platform selection, and a final project. Reading alone does not guarantee midlevel proficiency: the exercises and independent project are part of the path.

## What's new

- Replaces the four original demo courses once, while preserving imported lessons and preferences.
- Scrollable long-form cards with links, local diagrams, lists, and code.
- Sources open in your default browser. Bundled lab files can be saved from the lesson.
- Dependency-free lexical retrieval baseline with synthetic data, access filtering, and mock-tool checks. Optional inference connects only to an existing local Ollama service; no model is downloaded.
- Full lesson source: [course index](https://github.com/Hamrez95/Joree/tree/main/public/lessons/company-ai), [combined Markdown](https://github.com/Hamrez95/Joree/blob/main/public/lessons/company-ai/company-ai-complete.md).

## Downloads

- **JoreeSetup.exe**: installs for your current Windows account; no app-installer elevation.
- **Joree-0.3.0-win-x64.zip**: extract and run; uses the same shared runtimes.
- **Joree-lesson-template.md**: template for your own lessons.
- **INSTALL.md**: installation instructions.
- **SHA256SUMS.txt**: checksums for those four files.

Windows x64 requires .NET 10 Desktop Runtime and Microsoft Edge WebView2 Runtime. The preview is unsigned and framework dependent. Lesson text and diagrams work offline; external sources need a browser/network, and the optional model lab needs separately approved local tooling.
