# لوگو و آیکن جرعه

لوگوی جدید با نام فارسی «جرعه»، رنگ آبی و بنفش پاستیلی، صفحهٔ کرم، فنجان زرد و کارت آموزشی تولید شد. این دارایی مخصوص آیکن برنامه، نصاب، نوار وظیفه و میان‌بر دسکتاپ است؛ نشان داخل بدنهٔ رابط از مرجع قبلی حفظ شده است.

- تصویر اصلی پروژه: `public/assets/joree-app-icon.png`
- PNG ویندوز: `src-tauri/icons/icon.png`
- آیکن چنداندازهٔ ویندوز: `src-tauri/icons/icon.ico`
- اندازه‌های ICO: ۱۶، ۲۴، ۳۲، ۴۸، ۶۴، ۱۲۸ و ۲۵۶ پیکسل.
- ابزار تولید: ابزار داخلی `image_gen` با پس‌زمینهٔ شفاف؛ CLI یا کلید API استفاده نشد.
- بازتولید خروجی ICO از تصویر موجود: `powershell.exe -NoProfile -File scripts/export-app-icon.ps1`

متن پرامپت در `docs/branding-prompt.txt` نگه داشته شده است. تولید دوباره ممکن است خروجی متفاوتی بدهد؛ تصویر اصلی نسخه‌بندی شده است.
