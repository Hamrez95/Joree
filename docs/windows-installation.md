# نصب ویندوز بدون دسترسی ادمین

نسخهٔ ۰٫۲٫۳، ۸ نوامبر ۲۰۲۶.

برنامه با میزبان .NET 10 و WebView2 ویندوز، همراه با همان فرانت Svelte ساخته شده است. این انتخاب به‌دلیل مسدودشدن دانلود Rust در شبکهٔ شرکت انجام شد. هیچ پروکسی جایگزین، تغییر سیاست امنیتی، غیرفعال‌کردن آنتی‌ویروس یا دسترسی ادمین استفاده نشده است. اسکلت Tauri برای ادامهٔ مسیر اولیه حفظ شده، اما خروجی نصب‌شوندهٔ فعلی Tauri نیست.

## مسیرها

- فایل نصب: `C:\Projects\Joree\release\JoreeSetup.exe`
- بستهٔ قابل استخراج: `C:\Projects\Joree\release\Joree-0.2.3-win-x64.zip`
- برنامه: `%LOCALAPPDATA%\Programs\Joree\app-0.2.3\Joree.exe`
- میان‌بر منوی Start: `Joree`
- میان‌بر دسکتاپ: `جرعه.lnk` با لوگوی جدید.
- داده: `%LOCALAPPDATA%\Joree\learning.sqlite3`
- موقعیت پنجره: `%LOCALAPPDATA%\Joree\window.json`
- گزارش خطا، در صورت رخ‌دادن خطا: `%LOCALAPPDATA%\Joree\errors.log`

نصاب فقط در پوشه‌های کاربر و `HKCU` می‌نویسد و manifest آن `asInvoker` است. در تست نصب، `elevated: false` ثبت شد. برنامه به .NET Desktop Runtime 10 و WebView2 موجود در همین سیستم تکیه دارد؛ این دو پیش‌نیاز از قبل نصب بودند. این بسته برای سیستم‌های فاقد این پیش‌نیازها یک بستهٔ کاملاً مستقل نیست.

## رفتار برنامه

- اجرا بدون dev server، Node، مرورگر جداگانه یا اتصال اینترنت.
- صفحهٔ محلی با virtual host اختصاصی WebView2 بارگیری می‌شود؛ سرور HTTP باز نمی‌شود.
- ذخیرهٔ درس، موقعیت مطالعه، یادداشت و مرور در SQLite ویندوز انجام می‌شود. فرانت فقط فرمان‌های محدود دارد و SQL یا فایل‌سیستم عمومی در دسترس آن نیست.
- کنترل‌های کوچک‌کردن، همیشه‌بالا و حالت کوچک به پنجرهٔ واقعی متصل‌اند.
- بستن پنجره، برنامه را کنار ساعت مخفی می‌کند؛ برای خروج کامل از منوی آیکن کنار ساعت استفاده کنید.
- اجرای مجدد، پنجرهٔ موجود را باز می‌کند و نمونهٔ مستقل دیگری نمی‌سازد.
- موقعیت پنجره حفظ و در صورت نبود مانیتور قبلی به محدودهٔ معتبر برگردانده می‌شود.
- داده‌های نسخهٔ مرورگر خودکار خوانده نمی‌شوند؛ برای انتقال، در مرورگر نسخهٔ پشتیبان بگیرید و در نسخهٔ ویندوز بازیابی کنید.

حذف برنامه از Windows Installed apps با نام `جرعه / Joree` انجام می‌شود. حذف، دادهٔ یادگیری را نگه می‌دارد. اجرای خودکار هنگام ورود ویندوز فعال نشده است.

## ساخت مجدد

```powershell
pwsh -NoProfile -File scripts/build-windows.ps1
```

اسکریپت، فرانت و میزبان را می‌سازد، SHA-256 فایل‌های بسته را ثبت می‌کند و نصاب تک‌فایلی تولید می‌کند. نصاب پیش از نصب صحت همهٔ فایل‌ها را بررسی می‌کند.

## حدود تحویل

طراحی رابط تغییر نکرده است. تفاوت‌های بصری قبلی در فونت و حجم‌پردازی CSS همچنان وجود دارند. واردکنندهٔ Markdown فعلی از قالب ساده و سؤال/پاسخ پشتیبانی می‌کند؛ قالب پیشرفتهٔ frontmatter و به‌روزرسانی درس با شناسهٔ نویسنده هنوز کامل نیست. اعلان سیستم، اجرای خودکار اختیاری و مهاجرت میزبان به Rust/Tauri جزو موارد تکمیل‌نشدهٔ مشخصات اولیه‌اند. این نصب، تکمیل همهٔ بندهای مشخصات طولانی اولیه را اثبات نمی‌کند.
